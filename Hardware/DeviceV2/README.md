# DeviceV2
DeviceV2 is our model for three phase meassurements.

## Specs
  - Three phase/Three phase and neutral/Single phase, allow multiple configurations
  - 24000Hz sample rate
  - External current probes, allow 3.3v and 5v powered ones.
  - DIN rail Enclosure

## Drawbacks
  - Leak RTC
  - Not work from battery as expected, some changes needed.

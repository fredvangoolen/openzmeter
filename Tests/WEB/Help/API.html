An Application Programming Interface API has been implemented to access all the available information inside oZm in real time, some functions are intended only for WEB interface use, other are more useful to query the system from external programs.

To gather specific information, POST request are sent to the embedded web server. The server replies with an JSON object with the requested parameters. Input parameters is olso requiered to be valid JSON.

The web server requieres authorization by default (for example, a web session has been initiated), except for <code>localhost</code> petitions, which are authorized by default. In localhost, the user must be supplied as additional ‘Username’ parameter in queries. This allow to impersonate named user.

LogIn

Create a user session for laters queries.

Inputs params Type Requiered Default Notes
Username string false
Password string false
UpdateLastLogin boolean false true if set to true updates the last login information for the user to current time
Outputs params Type Notes
Result boolean true if logins success, also COOKIE is set in HTTP header
LastLogin uint64 Last login timestamp

getNews

Retrieve software changes, news or usage instructions since last user login.

Inputs params Type Requiered Default Notes
LastLogin uint64 true Retrieve messages since this timestamp
Outputs params Type Notes
Headers [string] Sorted from older to newer
Contents [string] Same order as headers
Timestamp [uint64] Same order as headers

getTimeSettings

Retrieve system timezones, and current NTP configuration. Requieres no input params.

Inputs params Type Notes
TimeZones [string] System allowed time zones
TimeZone string Current time zone
NTP_Enabled boolean Tell if NTP server is active or not
NTP_Server string Tell NTP server IP or name
Time int64 Current system timestamp in UTC

setTimeSettings

Save system timezones, and current NTP configuration.

Outputs params Type Notes
TimeZone string Current time zone
NTP_Enabled boolean Tell if NTP server is active or not
NTP_Server string Tell NTP server IP or name
Time int64 Current system timestamp in UTC
Ouputs params Type Notes
Result boolean true on success

Operation can fail if configuration file is read only or service is running under unprivileged user.
Time is updated only is NTP server is disabled, otherwise ignored.
